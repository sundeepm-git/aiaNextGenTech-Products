# Wix-to-YouTube Enterprise Automation (Bulk & Future-Proof)

This professional-grade automation pipeline converts **all existing** and future Wix blog posts into narrated YouTube videos using high-quality neural TTS and automated video editing. It is 100% free and open-source.

---

## 📂 Project Structure
```text
wix-to-youtube/
├── .env                    # Secret keys and configuration items
├── requirements.txt        # Python dependencies
├── main.py                 # The master orchestrator (handles bulk processing)
├── api.py                  # FastAPI REST layer (async job-based)
├── client_secrets.json     # YOUR Google Cloud API Credentials (Manual Setup)
├── uploaded_posts.log      # AUTO-GENERATED: Tracks processed posts to prevent duplicates
├── src/
│   ├── __init__.py
│   ├── wix_fetcher.py      # RSS parsing and bulk content extraction
│   ├── media_generator.py  # Text-to-Speech (edge-tts) and Video (MoviePy)
│   └── yt_uploader.py      # YouTube Data API v3 integration
└── temp/                   # Auto-created folder for processing files
```

## 💻 Step 3: Source Code

### main.py (The Brain)
```python
import os
from dotenv import load_dotenv
from src.wix_fetcher import get_all_posts
from src.media_generator import create_video
from src.yt_uploader import upload_to_youtube

load_dotenv()

def is_already_uploaded(post_title):
    if not os.path.exists('uploaded_posts.log'): return False
    with open('uploaded_posts.log', 'r') as f:
        return post_title in f.read()

def log_upload(post_title):
    with open('uploaded_posts.log', 'a') as f:
        f.write(post_title + "\n")

def main():
    if not os.path.exists('temp'): os.makedirs('temp')
    
    print("--- Fetching all available Wix posts ---")
    posts = get_all_posts(os.getenv("WIX_RSS_URL"))
    
    for post in posts:
        if is_already_uploaded(post['title']):
            print(f"Skipping: {post['title']} (Already Uploaded)")
            continue

        print(f"Processing: {post['title']}...")
        try:
            video_path = create_video(post)
            upload_to_youtube(video_path, post['title'], post['description'])
            log_upload(post['title'])
            print(f"Successfully uploaded: {post['title']}")
        except Exception as e:
            print(f"Failed to process {post['title']}: {e}")

if __name__ == "__main__":
    main()
```

### src/wix_fetcher.py
```python
import feedparser

def get_all_posts(rss_url):
    feed = feedparser.parse(rss_url)
    posts = []
    for entry in feed.entries:
        posts.append({
            "title": entry.title,
            "content": entry.summary, 
            "description": f"Original Post: {entry.link}\n\nGenerated by AI Automation."
        })
    return posts
```

### src/media_generator.py
```python
import asyncio
import edge_tts
import os
from moviepy.editor import TextClip, AudioFileClip, ColorClip, CompositeVideoClip

def create_video(post):
    audio_path = "temp/voice.mp3"
    video_output = "temp/output.mp4"
    voice = os.getenv("TTS_VOICE", "en-US-AvaNeural")

    # 1. Generate High-Quality Neural TTS
    async def generate_audio():
        communicate = edge_tts.Communicate(post['content'], voice)
        await communicate.save(audio_path)
    asyncio.run(generate_audio())

    # 2. Build Video
    audio = AudioFileClip(audio_path)
    bg = ColorClip(size=(1920, 1080), color=(15, 15, 15)).set_duration(audio.duration)
    
    txt = TextClip(
        post['title'], 
        fontsize=70, 
        color='white', 
        size=(1700, 800), 
        method='caption'
    ).set_position('center').set_duration(audio.duration)

    final_video = CompositeVideoClip([bg, txt]).set_audio(audio)
    final_video.write_videofile(video_output, fps=24, codec="libx264", audio_codec="aac")
    
    return video_output
```

## 🔑 Step 4: YouTube API Setup
1. Go to **Google Cloud Console**.
2. Create a Project & Enable **YouTube Data API v3**.
3. Create **OAuth Client ID** (Desktop App).
4. Download JSON as `client_secrets.json` and put in root.

## 🚀 Execution

### CLI mode
Run: `python main.py`

### API mode (FastAPI)
Run: `uvicorn api:app --reload --port 8000`

Interactive docs: [http://localhost:8000/docs](http://localhost:8000/docs)

#### API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/` | Health check |
| `GET` | `/health` | Service health with timestamp |
| `GET` | `/posts` | Fetch all posts from Wix RSS feed |
| `GET` | `/posts/uploaded` | List already-uploaded post titles |
| `POST` | `/process` | Process a single custom post (async background job) |
| `POST` | `/process/bulk` | Bulk-process all RSS posts (async background job) |
| `GET` | `/jobs` | List all jobs |
| `GET` | `/jobs/{job_id}` | Check status of a specific job |

#### Example: Process a single post
```bash
curl -X POST http://localhost:8000/process \
  -H "Content-Type: application/json" \
  -d '{"title": "My Post", "content": "Hello world blog content", "privacy": "unlisted"}'
```
Response:
```json
{"job_id": "abc-123", "status": "queued"}
```

#### Example: Bulk process RSS
```bash
curl -X POST http://localhost:8000/process/bulk \
  -H "Content-Type: application/json" \
  -d '{}'
```

#### Example: Check job status
```bash
curl http://localhost:8000/jobs/abc-123
```
